Computer Networks — Student Project Catalogue
Assoc. Prof. PhD. Nicolaie Popescu-Bodorin, 2022-2026

108 projects based on Weeks 1–7 (lecture, seminar and laboratory) · 36 per grade band · Deliverables: Word document + application

How to use this catalogue
  • Projects are coded A01–A36 (grade 5–7), B01–B36 (grade 7–8) and C01–C36 (grade 8–10). The grade band is the maximum achievable grade if all requirements are met.
  • Each project lists a plan of work, project-specific application features and document content; the standard tier requirements below apply in addition.
  • Network scanning, capture and attack-related projects must be performed only on the student's own machines or the isolated lab network.
  • Course languages: C on Linux (Labs 3, 5) and Java (Week 7). Other languages require coordinator approval.

  • Cover page (title, student, group, academic year, coordinator)
  • Table of contents
  • 1. Introduction — problem statement and objectives
  • 2. Theoretical background — the course concepts used, with references to the lecture weeks
  • 3. Design — functional requirements, main components, simple diagram
  • 4. Implementation — key code fragments with explanation

Application — standard package
